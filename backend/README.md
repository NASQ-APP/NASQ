# الباك-إند — دولابي الذكي

قاعدة البيانات، الصلاحيات، والتخزين، ودوال الحافة اللي تخفي مفاتيح المزوّدين.

مبني على Supabase حسب المعمار في §19 من وثيقة المتطلبات.

---

## التشغيل المحلي

يحتاج [Docker](https://docs.docker.com/get-docker/) شغّال.

```bash
npm run db:start     # يشغّل Postgres + Auth + Storage + Realtime + Studio
npm run db:reset     # يعيد بناء القاعدة من الـmigrations ويشغّل seed.sql
npm run functions:serve
```

بعد `db:start` تطلع لك المفاتيح المحلية. حطّي `anon key` في
`frontend/.env.local`، و**لا تحطّين `service_role` هناك أبدًا**.

| الخدمة | العنوان |
|---|---|
| API | http://127.0.0.1:54321 |
| Studio | http://127.0.0.1:54323 |
| بريد الاختبار | http://127.0.0.1:54324 |

## قواعد ثابتة

**١ — RLS مع كل جدول من أول migration، مو لاحقًا.** الحماية على القاعدة، مو على
الواجهة. كل سياسة تحصر الصفوف بـ`auth.uid()`.

**٢ — مفتاح `service_role` ما ينزل الفرونت-إند.** يعيش في بيئة الدوال فقط.
العميل عنده `anon key` فقط، ويشتغل تحت RLS.

**٣ — مفاتيح مزوّدي الذكاء داخل الدوال حصريًا.** الدالة وسيط يخفي المفتاح
ويستدعي API خارجيًا.

**٤ — الصورة الشخصية ما لها سلّة تخزين.** تعيش في ذاكرة الجلسة في المتصفح
فقط، ومستثناة صراحة من التخزين. لا تُنشأ لها سلّة في أي migration.

**٥ — روابط موقّعة محدودة المدة** بدل الروابط العامة. السلّتان `items` و
`outfits` خاصّتان، وكل مستخدمة داخل مجلد باسم معرّفها.

**٦ — Deno مو Node.** ما فيه معالجة صور محلية داخل الدوال (`sharp` وأمثاله).
لو احتجنا معالجة ثقيلة فعلاً، نضيف خدمة Node مستقلة بجانب Supabase — مو الآن.

## قواعد سلامة البيانات

- حذف خزانة **لا** يحذف قطعها — تنتقل خارج الخزائن أو لأول خزانة متبقية.
- حذف قطعة **لا** يحذف الإطلالة — الرابط `on delete set null`، فالإطلالة تعرض
  عدد القطع المفقودة بدل ما تنكسر.
- القطعة لها لون أساسي واحد لأنها غرض حقيقي، مو منتج بألوان متعددة.

## مخالفة مقصودة لـ§16

الوثيقة تقترح «غياب سطر في `item_closets` = قطعة تجربة». استبدلناها بعمود
`items.source` صريح، لأن المبدأ ٦ يقول التنظيم اختياري — فالقطعة المملوكة
خارج أي خزانة حالة مشروعة، وما ينفع تُقرأ كقطعة تجربة.

## مسارات الدوال

Supabase يخدم الدوال على `/functions/v1/<اسم المجلد>`، فالمسارات صارت
`/tryon-start` بدل `/tryon/start` المذكور في §19. مصدر المسارات الوحيد في
الفرونت-إند: `frontend/src/infrastructure/http/client.ts`.
