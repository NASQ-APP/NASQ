# دعم بنترست — إضافة متصفح + خطّاف واحد

يخليك تفتحين أي **Pin** لقطعة ملابس، تضغطين زرًا واحدًا، فتوصل القطعة إلى
«قطع تحت التجربة» عندك.

---

## كيف يشتغل

```
صفحة الـPin            الإضافة تخزّن            تطبيقك
  [+ زر]      →      طابور محلي       →      usePinterestPieces
                    (ينتظر لين تفتحينه)         → تضيفينها بدالتك
```

الطابور مهم: تقدرين تضيفين قطعًا وتطبيقك مسكّر — تنتظر لين تفتحينه. وما
تُحذف من الطابور إلا بعد ما يؤكّد تطبيقك استلامها.

---

## الملفات

```
pinterest-extension/
  manifest.json            إعداد الإضافة (بنترست + تطبيقك المحلي فقط)
  background.js            الطابور
  content/pinterest.js     الزر داخل صفحة الـPin
  content/dulabi.js        يسلّم الطابور لتطبيقك

usePinterestPieces.ts      خطّاف React يستقبل القطع — بلا اعتماديات
```

## التركيب — ثلاث خطوات

### ١. عدّلي منفذ تطبيقك

في `pinterest-extension/manifest.json` غيّري `5173` لمنفذك لو كان مختلفًا:

```json
"matches": ["http://localhost:5173/*", "http://127.0.0.1:5173/*"]
```

**بدون هذا ما توصلك القطع.**

### ٢. حمّلي الإضافة

`chrome://extensions` ← فعّلي **وضع المطوّر** ← **تحميل غير مُحزَّمة** ←
اختاري مجلد `pinterest-extension`.

ثم من **التفاصيل ← وصول الموقع** اختاري **«على كل المواقع»**. لو بقيت «عند
النقر» ما يشتغل الزر إلا بعد ما تضغطين أيقونة الإضافة.

### ٣. ركّبي الخطّاف مرة واحدة

انسخي `usePinterestPieces.ts` في `src/hooks/`، وناديه على مستوى التطبيق:

```tsx
import { usePinterestPieces } from '@/hooks/usePinterestPieces'

export function App() {
  usePinterestPieces((piece) => {
    // اربطيها بدالة الإضافة عندك — أنتِ تقرّرين الفئة واللون
    addItem({
      name: piece.name,
      imageUrl: piece.imageUrl,
      sourceLink: piece.sourceLink,
      source: 'try',
    })
  })

  return <Routes />
}
```

خلاص.

## وش يوصلك بالضبط

```ts
type IncomingPiece = {
  name: string          // عنوان الـPin أو النص البديل للصورة
  imageUrl?: string     // أكبر صورة في الصفحة
  sourceLink: string    // رابط الـPin
  storeId: string       // 'pinterest'
}
```

**ما فيه فئة ولا لون ولا سعر** — بنترست ما تنشرها. الاسم غالبًا تعليق («outfit
inspo») مب اسم منتج، **فلا تستنتجي منه الفئة إلا لو فيه كلمة واضحة** مثل
`dress` أو «تنورة». وإلا خلّيها «غير محددة» وتختارينها المستخدمة.

---

## الأمان

- **بيانات غير موثوقة:** الرسالة تجي من صفحة ما نملكها، فالخطّاف يقرأ الحقول
  المعروفة فقط ويتحقّق من أنواعها وأطوالها، ويرفض أي رابط مب `http`/`https`.
- **بلا تكرار:** كل رسالة لها معرّف، والمعرّف المتكرّر يُتجاهل.
- **بلا بيانات دخول:** الإضافة ما تقرأ إلا الصفحة اللي فتحتِها، وما تقرأ إلا
  عند الضغط. ما تلمس حسابك في بنترست.
- **الأذونات:** `storage` فقط.

---

## لو ما ظهر الزر

الزر يظهر في صفحة **Pin مفرد** (`/pin/…`) وفيها صورة بضلع ≥ ٢٤٠px — مب في
الصفحة الرئيسية ولا نتائج البحث.

للتأكد إن السكربت شغّال: افتحي Pin ← `F12` ← **Console** ← لازم تشوفين:

```
[بنترست → قطع التجربة] السكربت شغّال
```

ما ظهر السطر؟ ارجعي للخطوة ٢ — الأغلب إن **وصول الموقع** على «عند النقر»، أو
الإضافة تحتاج **إعادة تحميل** ⟳.
