# طبقة Supabase

هذا المجلد مخصّص للاتصال بـSupabase في المرحلة ١ (الخادم والحساب):

- `client.ts` — عميل المتصفح بـ`anon key` فقط، ويشتغل تحت RLS
- `database.types.ts` — أنواع مولّدة من مخطط القاعدة

الأنواع تُولَّد من الباك-إند ولا تُكتب يدويًا:

```bash
npm run db:types
```

**قاعدة أمنية (§17):** مفتاح `service_role` ومفاتيح مزوّدي الذكاء **ما تنزل
هنا أبدًا**. مكانها بيئة Edge Functions في `backend/`.

المجلد فاضي عمدًا لين تنبدي المرحلة ١ — إضافة عميل قبل وجود مشروع فعلي تضيف
اعتمادية بلا فائدة.
