# دولابي الذكي

خزانة ملابس رقمية شخصية، مع طبقة تجربة تعرض القطعة على شخص بمقاساتك قبل ما
تلبسينها أو تشترينها.

**مو متجر.** ما فيه سلة ولا دفع ولا سعر معروض للبيع. القطع اللي في التطبيق هي
قطعك أنتِ.

---

## التشغيل

```bash
npm install
npm run dev
```

الواجهة تشتغل بالكامل بدون خادم — البيانات في متصفحك. لتشغيل الباك-إند معها
راجعي [backend/README.md](backend/README.md).

| الأمر | وش يسوي |
|---|---|
| `npm run dev` | الفرونت-إند على وضع التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run typecheck` | فحص الأنواع (الوضع الصارم) |
| `npm run lint` | الفحص الثابت |
| `npm run db:start` | تشغيل Supabase محليًا (يحتاج Docker) |
| `npm run db:reset` | إعادة بناء القاعدة من الـmigrations |
| `npm run functions:serve` | تشغيل دوال الحافة محليًا |

## البنية

مجلدان مستقلان تمامًا، ما يستورد أحدهما من الآخر:

```
دولابي الذكي/
├── frontend/     ← React 19 · TypeScript · Vite · Tailwind v4
└── backend/      ← Supabase: Postgres + RLS + Storage + Realtime + Edge Functions
```

الفرونت-إند يكلّم الباك-إند عبر ملف واحد فقط:
[`infrastructure/http/client.ts`](frontend/src/infrastructure/http/client.ts).
تغيير عنوان الخادم أو مساراته تعديلٌ في مكان واحد.

## الفكرة

تصوّرين الملابس اللي عندك فعليًا ← تنحفظ في خزائن ← تنسّقين منها إطلالات على
موديل بمقاساتك (أو على صورتك) ← تحفظين الإطلالة وتلبسينها.

القطع من برّا (شي إن، نمشي، …) تدخل قسم **قطع للتجربة** فقط: تجرّبينها على
موديلك، وما تدخل خزانتك إلا لو اشتريتيها فعليًا ونقلتيها بنفسك. هذا الحد هو
اللي يمنع المنتج من الانزلاق لمتجر.

## مبادئ المنتج

قواعد ملزمة — أي ميزة جديدة تُقاس عليها قبل ما تُبنى.

1. **مو متجر.** ما فيه سلة ولا سعر بيع ولا زر شراء في أي شاشة.
2. **الاقتراح من خزانتك فقط.** الستايليست ما يقترح قطعة ما تملكينها.
3. **شخص واحد ثابت.** بذرة مقفولة تُشتق من المواصفات وتُمرَّر لكل توليد.
4. **ما نزيّف نتيجة.** أي شي ما يقدر عليه المزوّد يُقال صراحة.
5. **الصورة ملك صاحبتها.** ما تُخزّن ولا تُستخدم للتدريب، وزر الحذف ظاهر.
6. **التنظيم اختياري.** ترمين كل شي في الخزانة وتشتغلين.
7. **الإضافة بلا ألم.** رفع صورة = ثانيتين، والباقي على الذكاء.
8. **العربي مواطن درجة أولى.** RTL أصلي بخصائص منطقية، مو إنجليزي معكوس.

## اللي مو حقيقي في هذي النسخة

- صور الملابس والموديل **رسومات SVG** مولّدة، مو صور فوتوغرافية.
- ربط المتاجر واستيراد الروابط **محاكاة** — مكتوبة بوضوح داخل الشاشة.
- الباك-إند **سكافولد جاهز**: الجداول والـRLS ودوال الحافة مكتوبة، لكن الفرونت-إند
  لسه يقرأ من التخزين المحلي. الربط الفعلي هو المرحلة القادمة.
