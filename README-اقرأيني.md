# رفّ «قطع تحت التجربة» — النسخة النهائية

ملف **واحد** تنسخينه في مشروعك وتستوردينه. ما يستبدل أي ملف عندك، وما ينقل
لك تصميمًا ثانيًا — يندمج مع الديزاين اللي عندك كما هو.

---

## اللي فيه

- رفّ نحاسي بحاملين، والقطع **متدلّية** منه بعلّاقات
- العنوان «قطع تحت التجربة» ومعه العدد
- زر **«عرض الكل»** جنب العنوان — يتحوّل إلى **«اعرضي أقل»** عند الضغط
- الافتراضي **شريط أفقي** ينزلق يمينًا ويسارًا · وعند «عرض الكل» يصير شبكة
- عند المرور: القطعة ترتفع، ظل دافئ، وخيط نحاسي ينفتح تحتها

## اللي **ما** فيه — بقصد

| | |
|---|---|
| ❌ خلفية داكنة | البطاقة على سطح فاتح |
| ❌ خلفية صفحة أو تنسيق عام | المكوّن ما يرسم خلفية إطلاقًا — يجلس على خلفيتك |
| ❌ خطوط أو أحجام عامة | يرث خط مشروعك |
| ❌ مودل · وكيل · بنترست · Supabase | ولا سطر |
| ❌ مفاتيح أو `.env` | ولا ملف |

**الاعتماديات: React وTailwind فقط.** ما فيه راوتر ولا متجر حالة ولا مكتبة
أيقونات ولا نظام ألوان. كل لون مكتوب صريحًا داخل الملف، فيشتغل من أول لصقة
بلا أي إعداد.

## التركيب — خطوتان

### ١. انسخي الملف

```
src/components/TryPiecesRail.tsx
```

### ٢. استوردي وحطّي القطع

```tsx
import { TryPiecesRail, type RailPiece } from '@/components/TryPiecesRail'

const pieces: RailPiece[] = myItems.map((item) => ({
  id: item.id,
  name: item.name,
  imageUrl: item.imageUrl,
  meta: `${item.category} · ${item.price} ر.س`,
  badge: item.store,
}))

<TryPiecesRail pieces={pieces} onSelect={(id) => openItem(id)} />
```

خلاص. **ما فيه خطوة ثالثة، وما فيه ملف تستبدلينه.**

## الخصائص

| الخاصية | النوع | الافتراضي |
|---|---|---|
| `pieces` | `RailPiece[]` | **مطلوبة** |
| `title` | `string` | `'قطع تحت التجربة'` |
| `latin` | `string` | — تسمية صغيرة بجانب العدد |
| `empty` | `string` | `'الرفّ فاضي.'` |
| `onSelect` | `(id: string) => void` | — عند الضغط على قطعة |
| `className` | `string` | — لضبط الهوامش |

```ts
type RailPiece = {
  id: string
  name: string
  imageUrl?: string   // غيابها ما يكسر شي
  meta?: string       // «فساتين · ١٧٥ ر.س»
  badge?: string      // اسم المتجر فوق الصورة
}
```

حالة «عرض الكل» داخلية — ما تحتاجين تديرينها.

## الألوان — لو حبيتِ تطابقينها مع تصميمك

خمس قيم داخل الملف، بدّليها وخلاص:

| القيمة | وين تظهر |
|---|---|
| `#B08A57` | النحاس: الرفّ · العلّاقة · العدد · الخيط |
| `#FBF8F3` | سطح البطاقة والزر |
| `#E2D9CC` | حدّ الزر |
| `#1A1613` | العنوان واسم القطعة |
| `#A89C8F` | السطر الصغير والحالة الفاضية |

لو تبينه يذوب في تصميمك تمامًا، غيّري `bg-[#FBF8F3]` في البطاقة إلى
`bg-transparent`.

## متطلبات

- **React 18+** — يستعمل `useState` فقط
- **Tailwind 3.3+ أو 4** — بسبب `line-clamp` و`snap` والقيم بين الأقواس
- **RTL:** المكوّن يضبط `dir="rtl"` على جذره بنفسه، فيشتغل حتى لو صفحتك
  إنجليزية

## تنبيه واحد

الحشوة الرأسية في الشريط (`pt-1 pb-4`) مقصودة: `overflow-x` يقصّ رأسيًا كمان،
وبدونها ينقصّ ارتفاع البطاقة وظلها عند المرور. **لا تشيلينها.**
